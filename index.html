Evolution of U.S. Consumer Retail Behavior (2010–2025)

Created an interactive Power BI report to analyze the long-term shift from physical retail to e-commerce in the United States. The project evaluates retail-sales trends, differences in online adoption across business categories, and the structural effect of the 2020 pandemic on consumer purchasing behavior.

Tools: Power BI, Power Query, DAX, data visualization, trend analysis, and business storytelling.

Key Findings

  • E-commerce sales grew faster than physical retail sales.
  • Online sales represented an increasing share of total U.S. retail activity.
  • Retail categories showed different levels of online adoption.
  • Online retail penetration increased after 2020 and remained above its pre-pandemic trend.

Healthcare EMR Analytics System (Capstone Project)

Developed a Python-based healthcare analytics application that integrates patient-data retrieval, cleaning, analysis, filtering, reporting, and visualization within a single menu-driven system. The application simulates healthcare data workflows using publicly available API records and demonstration patient information.

Result: Delivered a functional analytics tool that transforms raw patient data into structured summaries, visual reports, and decision-support insights through an interactive, menu-driven interface.

Python REST API Pandas Matplotlib JSON Data Analytics

Key Contributions

  • Built an end-to-end pipeline to retrieve, validate, clean, and process patient records from a REST API.
  • Added offline demonstration data so the application remains functional when the external API is unavailable.
  • Calculated patient totals, unique email domains, medical condition frequencies, and average patient age.
  • Created bar charts, pie charts, and histograms to communicate condition prevalence and patient age distribution.
  • Implemented age-range filtering and automated generation of filtered analytical reports.
  • Designed a menu-driven interface with input validation and error handling.
Data note: This application uses publicly available and simulated demonstration data. It does not contain real patient information and is not intended for clinical use.
